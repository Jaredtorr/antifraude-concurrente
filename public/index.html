Tarjetas POST /tarjetas/:id/autorizar · cluster + IPC

Cada tarjeta tiene 5 intentos por minuto. El contador vive en el proceso primario, así que cuenta igual aunque te atienda otro proceso: el PID cambia, el límite no.

Lotes POST /lotes · worker_threads

Revisión pesada de transacciones. El servidor contesta 202 al instante y el cálculo corre en el pool. Mira las sucursales de arriba: los cajeros se ocupan y /health sigue respondiendo.

Análisis POST /analisis · child_process + Python

Sube un CSV de transacciones (el de python/generar_datos.py). El servidor lanza detectar.py como proceso externo y devuelve las sospechosas línea por línea. Si cancelas, el servidor mata al proceso hijo.
